# clean-workspace-cli

## 2.0.0-beta.0

### Major Changes

- Add a unified, read-only Smart Scan for workspaces, global developer caches,
  and supported macOS system locations.
- Route every cleanup through an inspectable plan and central path safety
  policy, without shell-interpolated deletion.
- Add controlled automation with dry-run, apply, explicit targets, safe/deep
  presets, stable JSON output, configuration, exclusions, and exit codes.
- Add per-item cleanup receipts, history, interruption handling, partial
  failure reporting, and a refreshed interactive dashboard.
